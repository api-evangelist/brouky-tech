Brouky provides a searchable database of over 37,000 venture capital firms and angel investors, ranking them by likelihood to back startups. The platform offers free search, fit scores, co‑investor maps, portfolio signals, and tracking tools for founders to manage fundraising without login or subscription.

**Areas:** VC · Fundraising · Startup · Investor-Intelligence · Analytics

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Brouky: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
